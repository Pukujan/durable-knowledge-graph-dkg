# Contradiction Review

Load this methodology when claims or sources appear to disagree.

1. Retrieve each position and its source evidence separately.
2. Distinguish contradiction, challenge, refinement, temporal change, and different scope.
3. Treat multi-model agreement as review metadata, not evidence.
4. Preserve unresolved disagreement as a valid state.
5. Propose explicit relation/state events with provenance; do not overwrite an earlier claim.
6. Commit only through the durable corpus boundary after validation and write-permission checks.
