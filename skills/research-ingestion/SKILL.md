# Research Ingestion

Load this methodology when adding source material or converting research into corpus events.

1. Preserve source bytes/artifacts before deriving knowledge when primary evidence is available.
2. Label reconstructed material as reconstructed; never silently promote it to verbatim evidence.
3. Keep claims, assumptions, challenges, rebuttals, and uncertainty separately addressable.
4. Attach stable evidence/source refs to proposed events.
5. Include actor/model/harness/skill provenance on agent proposals.
6. Validate pack write boundaries and event schema before commit.
7. Commit durable events before any graph/vector projection work.
