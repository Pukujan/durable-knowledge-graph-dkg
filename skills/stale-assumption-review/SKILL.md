# Stale Assumption Review

Load this methodology when a premise, dependency, or source has been superseded or may have decayed.

1. Find the changed premise and all dependent claims/relations.
2. Retrieve the evidence that supported the old state and the evidence that changed it.
3. Preserve the old state/history; do not rewrite it away.
4. Distinguish `stale_pending_review` from disproven or retracted.
5. Propose explicit refreshed state/relation events only when evidence justifies them.
6. Keep review provenance and commit through the durable corpus service.
